# Organizador de archivos

Script en Python que ordena los archivos de una carpeta en subcarpetas según su tipo (imágenes, documentos, videos...).

## Cómo usarlo
1. Instala Python 3
2. Ejecuta: `python organizadorArchivos.py`
3. Escribe la ruta de la carpeta que quieres organizar

## Tecnologías
Python (os, shutil)
